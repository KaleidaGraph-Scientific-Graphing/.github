## KaleidaGraph Highlights

- **Error Bars As A First-Class Habit:** KaleidaGraph scientific graphing expects columns of means and errors from an experiment you already analyzed, not a naked spreadsheet line.
- **Overlay Fits You Choose:** KaleidaGraph curve overlay drops a model on KaleidaGraph publication plot without sending you to a separate stats GUI.

- **Transforms On The Table:** New columns from formulas on data you measured, then plot those.

## What Is KaleidaGraph

KaleidaGraph is a Windows (and classic Mac) scientific graphing program. Biologists, chemists, and engineers who already have a results table open KaleidaGraph scientific graphing because default Excel charts fail a reviewer. KaleidaGraph publication plot is the page. KaleidaGraph curve overlay is the fit. KaleidaGraph lab graph is the file you keep with the manuscript.

SigmaPlot is the other famous biology-graph brand, with a heavier template and stats wizard culture. QtiPlot and SciDAVis are Origin-like. KaleidaGraph’s identity is clean 2D publication graphs, error bars, and formula columns on a table you own.

Graph results you measured or were given for a paper you write. Keep the file with the submission folder. Do not reuse another lab’s unpublished figure layout as if it were your data.

## Starting with KaleidaGraph

Prerequisites: A PC you administer and a results table from an experiment you are allowed to publish.

1. **Prepare:** Arrange means, errors, and X from the analysis you already ran.
2. **Configure:** Import into KaleidaGraph scientific graphing and name columns as the figure legend will read.
3. **Test:** Plot one series with error bars and confirm a point against the table.
4. **Refine:** Add KaleidaGraph curve overlay, then set fonts and units for the journal.
5. **Apply:** Build remaining panels of KaleidaGraph publication plot for that paper.
6. **Maintain:** Store KaleidaGraph lab graph with the manuscript version, and start a new file for a new figure set.
